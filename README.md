# 信号塔 XinHaoTa 📡

一个把"主力行为学"那套**A股盘感打法**变成**看得见、点得动、能自己跑**的本机看盘工具。

> 说人话：你在各种复盘里听过的"线上持股线下持币""倒车接人别接飞刀""一条裤子轮流穿"，这里把它变成——打开网页，每只自选股直接给你 **买 / 观望 / 卖 / 持股** 三态结论 + 参考买卖点 + 为什么。数据自己从免费源拉，行情自己刷，不用盯盘软件。

## 它解决什么

- **不猜**：5天线在线上→持股，跌破→走。规则写成引擎，不靠盘感拍脑袋。
- **能扫**：一屏看全部自选股的红黄绿，谁该动谁该拿一眼知道。
- **有依据**：每个结论都带数字（收盘价 vs MA5/MA20、回撤、距顶天数），不是玄学。
- **不绑数据商**：行情源可插拔（默认新浪免费K线，稳定）。

## 一、两分钟上手（Windows）

**要求**：装了 Python 3.10+（`python --version` 能出数字即可）。别的都不用装。

**一键（推荐）**：
```powershell
# 1. 下载本项目并解压（或 git clone）
# 2. 双击 install.bat   → 自动检查 Python、装可选依赖、启动服务并打开浏览器
# 3. 或用任一命令入口：
start_web.cmd                      # 双击启动网页版
python web_server.py 8090          # 或手动命令
```
浏览器打开 `http://127.0.0.1:8090/` 即可。
首次打开，点左上 **"🔄 立即更新行情"**，几秒后自选股就有数据和结论了。

> 完全本机运行：平台只绑 `127.0.0.1`，你的自选股/数据都留在自己电脑。

## 二、能干什么

- **自选股**：网页左侧搜索添加（支持代码/名称/拼音，如 `600519` / `茅台` / `zg`）、删除、上下拖拽排序。
- **三态结论**：每只票给 买/观望/卖/持股 + 理由 + 参考入场/止损/支撑压力。
- **K线与均线**：日/周/月线 + MA5/10/20 切换。
- **大脑开关**：主力行为学 11 个技能可单独开关——关掉某技能，结论真的会变（试试关掉"5天线战法"）。
- **市场环境**：龙头定高度 / 板块轮动 / 鲸落万物生 / 后四分之一 一键看。
- **全市场行业浏览**：49 个行业 → 点进去看成分股 → 点股票直接看它的买卖点，还能一键加自选。
- **定时刷新**：设个时间，每天到点自动更新行情。
- **多主题**：左上角"风格"下拉，深色原版 / 苹果玻璃 / 黑金 / 纸张浅色，一键换皮。
- **远程访问（可选）**：自带 cloudflared + 密码代理，手机扫二维码也能看（详见 `docs/远程访问.md`）。

## 三、数据源（默认新浪，免费稳定）

改根目录 `datasource.json` 即可换源，无需改代码：

```json
{ "type": "sina" }        // 默认：新浪前复权K线（稳定，含日/周/月）
```

| type | 来源 | 说明 |
|------|------|------|
| `sina` | 新浪财经 | 默认，免费、稳定、不受限流 |
| `tencent` | 腾讯 | 备用 |
| `eastmoney` | 东方财富 | 免费但偶发反爬限流 |
| `file` | 本地文件 | 读 `data/custom/<code>.json`，断网可用/接自己的数据 |
| `http` | 自定义 API | 返回统一格式 rows JSON 即可 |

详见 [`docs/数据源接口.md`](docs/数据源接口.md)。

## 四、远程访问（可选，含 cloudflared）

手机/任意设备打开浏览器访问本机平台：

1. 自备 `cloudflared`（官方免费）：把 `cloudflared.exe` 放进本项目 `bin/`，或加入系统 PATH。
2. 双击 `start_remote.cmd`（起平台 + 密码代理 + 隧道）。
3. 网页右上角"远程访问"菜单：看公网 URL、扫二维码、改密码、开关隧道。

⚠️ **默认密码 `admin`，公网开放前务必改**。详见 [`docs/远程访问.md`](docs/远程访问.md)。

## 五、文件结构

```
XinHaoTa/
├── watchlist.md        ← 自选股示例（网页可增删）
├── datasource.json     ← 数据源配置（sina/tencent/eastmoney/file/http）
├── install.bat         ← ★ 一键安装并启动（检查Python+装依赖+开浏览器）
├── web_server.py       ← 网页服务（入口）
├── remote_proxy.py     ← 密码代理（远程访问用）
├── run.py              ← 命令行批量生成 Markdown 报告
├── start_web.cmd       ← 一键启动网页版
├── start_remote.cmd    ← 一键启动 网页+远程
├── bin/                ← 放你自己的 cloudflared.exe（可选）
├── src/                ← 引擎源码（主力行为学规则）
├── scripts/            ← 数据导出等工具
├── web/                ← 前端（index.html + 本地 ECharts）
├── docs/               ← 说明文档
└── data/               ← 运行时数据（自动生成，不入库）
```
