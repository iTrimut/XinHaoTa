# 示例：立昂微（605358）买卖点分析

> 本文件是 **XinHaoTa 平台输出格式的示例**（数据截至 2026-09-04，仅供了解平台长什么样，不构成任何投资建议）。

## 这个页面展示什么

在平台里点左侧任一自选股，右侧就会给出类似下面的内容：**结论在最上、理由带数字、买卖点可执行**。

## 一、核心结论（示例输出）

```
🟦 持股待涨 → 后来转为观望/卖出 的信号示例
```

为了演示"平台会随时间改判"，这里用立昂微的历史判例展示两种形态：

### 形态 A：跌破 5 日线 → 卖出/离场
当收盘价跌破 5 日线且中期走弱（收盘 < MA20 且 MA20 下行）时，引擎按"线上持股线下持币"判 **卖出/离场**，理由类似：
> 已跌破 5 日线且中期转弱，线下持币。收盘 41.75 < MA5(43.08) < MA20(44.28)。

### 形态 B：放量滞涨 / 破位 → 排除法警示
命中"破位下行 / 跌破 5 日线 / 放量滞涨"任一必跌特征时，引擎会**优先规避**（排除法），即使其它信号偏多。

## 二、引擎背后的判断依据（拿立昂微举例）

| 项 | 引擎怎么算 | 立昂微某日的值 |
|----|-----------|--------------|
| MA5 | 近 5 日收盘均值 | ≈43.1 |
| MA20 | 近 20 日收盘均值 | ≈44.3 |
| 状态 | 收盘 vs MA5/MA20 | ③ 线下持币（收盘低于两者） |
| 时空 | 距 60 日高点回撤 | 从高点 83+ 回落约 -40%+ |
| 排除 | 破位/放量滞涨 | 命中破位 |

## 三、怎么看这个平台输出的买卖点

表格里给的是**条件**而不是"包涨"的承诺：
- **参考入场（5 日线）**：站稳这条线上方才是"在线"
- **止损价（-3%）**：跌破就走，把判断错的风险锁死
- **近 20 日支撑 / 压力**：给个区间感，不是精确点位

> ⚠️ 一切都是规则输出，用于演示界面与逻辑；真实使用时请以你的实时盘面为准。
