# 信号塔（XinHaoTa）— 设计文档

> 记录"以主力行为学为大脑的A股买卖点平台"的架构与决策。开源版（含多主题 UI、数据刷新、定时、行业浏览、远程访问）。

## 1. 目标

面向**普通投资者**的 A 股买卖点分析平台：界面有**自选股选项** + 每票**买卖点** + **三态分析结论**。
核心=**个股详情页**（Obsidian Markdown），一页看懂"买/卖/观望 + 依据 + 市场环境"。

## 2. 关键决策（对用户问卷的回答）

| 维度 | 用户选择 | 影响 |
|------|---------|------|
| 使用对象 | 面向普通投资者 | 结论卡在前(三态+理由+依据)，指标在后，风险提示独立成块 |
| 平台形态 | Obsidian Markdown 驱动 | 生成 `.md` 详情页 + 看板，Obsidian 打开即看盘 |
| 大脑来源 | 11个技能全量规则化 | 把可计算的技能转成确定性引擎规则 |
| 结论输出 | 确定性规则:买/卖/观望三态+理由 | 引擎直接给三态，不需人再判读 |
| 数据源 | 免费接口(A股复权K线) | 东方财富 push2his，无需token |
| 股票池 | 手动维护自选股列表 | `watchlist.md` 为唯一配置 |
| 界面重点 | 个股详情页 | 一票一页，含走势均线+信号+买卖点+结论 |

## 3. 三层架构（借鉴 YMOS，但简化）

YMOS 是"判断主导、流程系统化"（人做最终判断）；本平台更进一步——主力行为学本身高度机械化，
故引擎**直接得出三态结论**。这是与 YMOS 的本质差异（见 README 对比）。

```
投研层(数据)      →     策略内核层(主力行为学大脑)      →     操盘层(输出)
data_fetch.py          signal_engine.py + context_engine   md_render.py
东方财富复权K线        个股信号(A层) + 市场环境(B层)        个股详情页+看板
```

## 4. 大脑规则化：11 技能 → 引擎

### A 层 · 个股硬信号引擎（v0.1 已实现）
- **ma5-core-strategy** → 四状态机：④线上持股 / ①倒车接人 / ②至暗时刻 / ③线下持币 + 3%止损
- **dual-mode-buying** → 倒车接人(右侧) vs 至暗时刻(左侧) 判据（MA20方向 + 相对位置）
- **spacetime-resonance-timing** → 空间位(回撤≥15%) + 时间(距高点≥5交易日) 双验证
- **exclusion-based-stock-picking** → 破位(close<MA20且MA20下) / 跌破5日线 / 放量滞涨(换手>8%却收跌) 剔除标记
- **行为层**：近因/盈亏同源/叶公好龙 → 展示不参与打分

### B 层 · 市场上下文引擎（v0.2 已实现）
- **leader-defines-height** → 龙头定高度：优先取"未破位且趋势向上"的旗舰为龙头；若样本全破位则标"无真龙头"=市场转弱
- **sector-rotation-framework** → 板块轮动：按 watchlist 的板块字段聚合相对强度，识别"穿裤子"vs"等裤子"
- **whale-fall-rebirth** → 鲸落万物弹：最强板块龙头跌破5日线 = 资金释放，弱势板块机会打开（"弹"非"生"）
- **last-quarter-stock-screening** → 后四分之一：按相对强度排序，标存活者(头部)与掉队者(尾部)

## 5. 三态结论判定逻辑（v0.1）

`state_machine` 判定四状态 → `verdict` 综合：
- ③线下持币 → **卖出/离场**（破位且中期转弱）
- ②至暗时刻 → **观望/不接飞刀**（需恐慌放量+收复5日线确认）
- ①倒车接人 / ④线上持股(弱) → 若**时空共振**(空间到位+时间充分)则 **买入/低吸**，否则 **观望/等确认**
- ④线上持股(强) → **持股待涨**

## 6. 文件职责

| 文件 | 职责 |
|------|------|
| `watchlist.md` | 自选股配置（Markdown 表格），用户唯一维护点 |
| `run.py` | 命令行主入口：读清单→抓数→分析→渲染 Obsidian .md |
| `web_server.py` | 网页可视化服务（标准库 http.server，零依赖） |
| `start_web.cmd` | 网页版一键启动脚本（双击） |
| `web/index.html` | 看板前端：K线图+均线(本地ECharts) + 三态结论 + 买卖点 + 市场环境 |
| `src/data_fetch.py` | 东方财富复权K线(个股+指数)，secid 自动判断，当天缓存，重试+批处理 |
| `src/signal_engine.py` | A层信号引擎（个股硬信号），无UI纯逻辑 |
| `src/context_engine.py` | B层市场上下文引擎（龙头/轮动/鲸落/后四分之一），无数据时优雅降级 |
| `src/md_render.py` | 渲染 Obsidian Markdown 详情页 + 看板 |

## 7. Web 版（v0.3）

面向普通投资者，真正的可视化界面：
- 左侧：自选股列表（每票: 名称/现价/涨跌/状态/三态徽章） + 市场环境（龙头/轮动/鲸落/后四分之一）
- 右侧：个股详情 —— 顶部三态结论横幅（配色区分买/观望/卖）+ K线/MA5/MA10/MA20 + 成交量 + 当前状态 + 买卖点表 + 排除法
- 图表：本地 ECharts（`web/echarts.min.js`，npm 拉取后拷贝进 web/，离线可用，不依赖国外 CDN）
- API：`/api/stocks`（全部+市场）、`/api/kline/<code>`（K线+均线+信号）
- 数据：复用 A/B 层引擎；当日缓存命中则不打网络，规避反爬

## 8. Web 版功能升级（v0.4）
- **增删股票**：`src/store.py` 持久化到 `config.json`（自选股 + brain），网页增删自动**写回 `watchlist.md`**（真相源保持一致）。API：`/api/watchlist/add` `/api/watchlist/del`
- **大脑选择**：`src/brain.py` 定义 11 技能元数据（分组 A层/B层/行为层 + 默认启用）。前端开关 → `store.set_brain` → `signal_engine.analyze(enabled)`/`context_engine.analyze_context(enabled)`，**关闭某技能会真正改变 verdict**（control 位 state/mode/spacetime/exclude 分别对应 5天线/双模式/时空共振/排除法）。带"全开 / 只看个股 / 只看大盘 / 保守空仓"预置
- **UI 布局重构**：顶栏 + 左栏(大脑选择/市场/自选股) + 右栏(详情)；卡片分区、大脑面板可折叠、增删按钮、涨跌配色统一

## 9. 数据源接口（v0.5，可插拔）

- **动机**：东方财富 K 线接口**反爬限流**导致"添加没反应/页面卡死/缓存丢失"。平台不能再绑死单一数据源。
- **架构**：`src/datasource.py` 定义 `DataSource` 基类 + 注册表 + `active_source()` 工厂；`data_fetch` 变为**门面**，把 `fetch_kline`/`fetch_stock_basic`/`fetch_many` 委托给当前激活源。
- **内置源**：`SinaSource`(**默认, 新浪前复权K线, 稳定不受限流, 日/周/月**) / `TencentSource`(备用) / `EastmoneySource`(易限流) / `FileSource`(读 `data/custom/<code>.json|csv`, 断网可用) / `HttpSource`(自定义API, `url_template` 支持 `{code}/{limit}`).
- **统一 rows 格式**：`{date,open,close,high,low,vol,amt,pct,to}` 升序，引擎只认这个格式，因此换源不影响信号/买卖点/大脑/市场环境。
- **切换**：改 `datasource.json` 的 `type`（sina/tencent/eastmoney/file/http），重启生效；网页顶部显示当前源。
- **API**：`/api/source` 返回当前源 + 可用源清单 + rows 格式说明。
- **可靠性**：`fast` 模式(单次超时5s/重试1)让批量/网页场景在限流时快速失败；刷新接口**不删缓存**(避免丢失唯一可用数据)。
- **(v0.11 强化)**：`SinaSource` 用 `quotes.sina.cn` 的 `CN_MarketDataService.getKLineData`，日 scale=240 / 周 scale=1200 / 月 scale=7200，返回前复权(与腾讯一致)，datalen 上限约320。默认源从 eastmoney 换成 **sina**。
- **行业源(独立模块)**：`src/industry.py` 用 **新浪财经** `newSinaHy.php`(49行业) + `getHQNodeData`(成分股)，稳定不受限流，非个股信号，仅用于"全市场行业浏览"。

## 10. 数据刷新与定时（v0.7）

- **动机**：自选股行情需要定期/手动更新到最新（本地 file 源不会自动变）。用户要求：①开机/定时自动刷新 ②页面手动刷新按钮 ③可设固定时间刷新。
- **`src/refresh.py`**：`refresh_all()` 线程安全(lock 防按钮/定时互相覆盖)，从实时源(腾讯兜底)重新导出 日/周/月 数据 + 清分析缓存 + 重算；`schedule_loop()` 后台线程每20s检查 `config.json` 的 schedule，到点(每天HH:MM)触发 refresh_all 一次。
- **schedule 配置**：`store.get_schedule()/set_schedule()`，存 `config.json` 的 `{"enabled":bool,"time":"HH:MM"}`。
- **后端 API**：`POST /api/refresh`(立即更新)、`GET /api/schedule`、`POST /api/schedule/set`、`GET /api/refresh_status`。
- **前端**：左栏"📡 数据刷新"卡片——"🔄 立即更新行情"按钮(带进行中/上次刷新状态) + "⏰ 定时刷新"设置(启用开关 + 时间选择器 + 保存)。
- **开机自动**：`web_server.py` 的 `main()` 启动时 spawn 调度线程，读 config 的 schedule，服务在跑即自动定时刷新。
