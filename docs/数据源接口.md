# 数据源接口（可插拔）

平台不绑定单一数据源。所有行情都经过 `src/datasource.py` 的统一接口，**改 `datasource.json` 即可换数据源，无需改代码**。

## 怎么切

编辑项目根目录的 `datasource.json`：

```json
{ "type": "eastmoney" }
```

- `eastmoney` → 东方财富免费复权K线（默认，免费无需token）
- `tencent` → 腾讯前复权日K（**备用，东方财富限流时用它**，通常不受限）
- `file` → 读本地文件（断网可用，接你自己的数据）
- `http` → 自定义 HTTP API

改完**重启** `web_server.py`（或重跑 `run.py`）即可生效。网页顶部会显示当前数据源。

## 一、导出真实行情到本地（推荐，先跑这个）

东方财富免费接口有时被反爬限流（表现为"行情暂不可用/添加没反应"）。**腾讯接口通常不受限**。
用附带脚本一键把自选股的真实行情导出到本地：

```powershell
python scripts/export_data.py                 # 导出 watchlist 全部股票
python scripts/export_data.py --dry           # 只探测, 不写文件
python scripts/export_data.py 605358 688981   # 只导指定几只
```
脚本优先用当前激活源，失败自动回退**腾讯**。导出结果写入 `data/custom/<code>.json`（统一rows格式）+ `<code>.name`（名称）。
成功后 `datasource.json` 设 `{"type":"file"}` 重启，即可用本地数据，彻底不依赖网络活数据。

## 二、用"本地文件"源（接自己的数据）

1. 建目录 `data/custom/`
2. 每个股票放一个文件，命名 `代码.json` 或 `代码.csv`：

**`data/custom/605358.json`**（统一字段，rows 升序）：
```json
[
  {"date":"2026-08-01","open":39.56,"close":35.68,"high":39.78,"low":35.60,"vol":492940,"pct":-9.46,"to":6.38},
  {"date":"2026-08-02","open":38.32,"close":37.10,"high":39.25,"low":37.08,"vol":553679,"pct":3.98,"to":7.17}
]
```

或 **`data/custom/605358.csv`**：
```csv
date,open,close,high,low,vol,pct,to
2026-08-01,39.56,35.68,39.78,35.60,492940,-9.46,6.38
2026-08-02,38.32,37.10,39.25,37.08,553679,3.98,7.17
```

3. 定义股票名（可选）：`data/custom/605358.name` 文件里写名称。

然后 `datasource.json` 设 `{"type":"file"}`，重启即可。

### 周期文件（日/周/月）

`export_data.py` 默认导**日/周/月三种**，`FileSource` 会按周期读取：
- 日线：`<code>.json`（如 `605358.json`）
- 周线：`<code>_week.json`（如 `605358_week.json`）
- 月线：`<code>_month.json`（如 `605358_month.json`）

网页"日线/周线/月线"按钮就是切这些文件。只想导某周期用 `--day-only` / `--week-only` / `--month-only`。

## 三、字段约定（所有源都返回这个格式）

`rows = [ {date, open, close, high, low, vol, amt, pct, to}, ... ]`（升序）
- `date`: `"YYYY-MM-DD"` 字符串
- `open/close/high/low`: 必填
- `vol/amt/pct/to`: 可给 0（引擎只用 close/high/low 算信号；成交量仅在放量滞涨判断用）

## 四、用"HTTP API"源（接自己的服务）

`datasource.json`：
```json
{ "type": "http", "url_template": "http://my-service/api/kline/{code}?limit={limit}" }
```
`{code}` 替换代码、`{limit}` 替换数量。你的接口返回统一格式 rows JSON（数组 或 `{"rows":[...]}`）。

## 五、为什么这样做

之前东方财富 K 线接口**反爬限流**（本会话实测多次"打不开"），造成"添加没反应/页面卡死"，且我一度清缓存导致数据丢失。
用可插拔源后：
- 你完全可以用自己的数据源 / 本地数据文件，**彻底摆脱限流**；
- 引擎、买卖点、大脑开关、市场环境**全部照常工作**（因为它们只认统一格式 rows）；
- 默认仍用东方财富（免费省事），哪天被限流就切"文件"或"http"。
