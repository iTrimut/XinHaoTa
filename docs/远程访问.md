# 远程访问（cloudflared + 密码代理）

信号塔（XinHaoTa）支持**远程访问**：手机/任意设备打开浏览器即可访问。

> 你需要自己准备 cloudflared 二进制：把 `cloudflared.exe` 放到本项目 `bin/` 目录，或加入系统 PATH（见下文）。

## 架构
```
[手机/任意设备] -> https://<随机>.trycloudflare.com  (cloudflared quick tunnel, 免费/零配置/免账号)
                -> http://127.0.0.1:8095  (本机密码代理, HTTP Basic)
                -> http://127.0.0.1:8090  (平台, 仅本机绑定)
```
公网入口先过**密码代理**（不看密码一律 401），平台本身只绑 127.0.0.1，不裸奔。

## 一键启动
```powershell
双击 start_remote.cmd     # 或 python scripts/start_remote.py
```
启动后控制台会打印公网地址（每次重启会变）。

## 页面里的菜单
网页**顶部最右上角的"远程访问"下拉菜单**：
- **本机**：`http://127.0.0.1:8090/`（可复制）
- **公网地址（免装 app）**：显示当前隧道 URL，点开可访问、可复制
- **📱 二维码**：公网隧道开启后自动显示二维码（**手机扫码即可访问 / 点"保存"下载 PNG**）
- **密码**：点"改密码"设置远程访问密码（公网入口需输入）
- **隧道状态 / 开-关按钮**：一键开启/关闭公网隧道（跨进程真正生效）

> 隧道开关由 `/api/remote/tunnel` 进程级管理（查找/启停真实 cloudflared 进程），不受哪个进程启动隧道影响。

## 手动命令
```powershell
# 只起隧道(公网暴露) 到代理8095
python scripts/start_remote.py
# 或单独:
python web_server.py 8090        # 平台
python remote_proxy.py 8095 127.0.0.1:8090   # 密码代理
cloudflared tunnel --url http://127.0.0.1:8095   # 公网隧道
```

## 接口
- `GET /api/remote` — 返回远程状态(代理/隧道/公网URL/是否鉴权)
- `POST /api/remote/tunnel {action:start|stop}` — 起/停隧道
- `POST /api/remote/password {pw}` — 改密码

## 安全
- 平台 web_server 只绑 **127.0.0.1**；公网只暴露代理 8095。
- 密码代理默认密码 `admin`（**建议立即在页面改掉**）。
- 密码存 `data/remote_pass.txt`、隧道地址存 `data/remote_state.json`（均已被 `data/` gitignore 保护，不入库）。
- **注意**：cloudflared quick tunnel 地址每次重启会变（自然轮换，旧链接失效），且免费无 uptime 保证；适合个人使用。若要固定域名需 Cloudflare 账号的 named tunnel。

## ⚠️ 说明
- 平台会保存你的自选股/运行数据（本地），公网开放前务必改掉默认密码 `admin`。
- 要彻底不暴露公网，可只在 `http://127.0.0.1:8090/` 本机使用，或改用 Tailscale 等私有组网。
